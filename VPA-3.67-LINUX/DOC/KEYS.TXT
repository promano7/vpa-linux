
This is the complete VPA hot-key list, that is also available during the play
via the F1 key ("Help").

Updated for VPA 3.62.


COMMON KEYS
-----------

Left Mouse Button is functionally equal to the Enter key
Right Mouse Button is functionally equal to the Spacebar key
Center Mouse Button is functionally equal to the Tab key

,->,,        - pointer movement (in keyboard-only mode)
Alt-,->,,    - accelerated pointer movement
Z               - center view around the pointer position
Tab/Shift-Tab   - zoom in/out
Ctrl-Tab        - zoom out to view entire galaxy
Shift-Alt-0..9  - store current map position
Alt-0..9        - retrieve stored map position
Shift-S,E,T,M,I,U,A,P,G,L,X,C,W
                - switch (on/off) visibility on the map of your ships (S),
                  enemy ships (E), traces (T), mine fields (M), ion storms (I),
                  wormholes and UFOs (U), markers (A), planet names (P),
                  gravity wells (G), planet connections (L) minefield
                  explosions (X), Clock (C) and Warp-Circles (W)
Alt-A           - next marker filter
Shift-B         - show ship build costs for choosen race
Shift-V         - reset mouse and video (if any problems)
+,-             - view next/previous turn data
Ctrl/+,-        - view last/first turn data
Spacebar        - scroll map window (if the pointer is close
                  to the map edge and no objects selected)
Spacebar        - Distance Mode on/off (if an object is selected)
Shift-Space     - enter Distance Mode (if no objects selected)
Enter           - select nearest object and view its info screen
Shift-Enter     - select nearest circle-shaped object
P,B             - select planet or SB under the pointer (if any)
0..9            - select another object at the same spot (if any)
PgUp,PgDn       - browse object list (if 10+ objects there)
,             - cycle through objects at the same spot
                  In keyboard-only mode: Ctrl-,
,->            - cycle through objects of the same type
                  In keyboard-only mode: Ctrl-,->
Esc             - leave any info or help screen
Ins             - set color marker at the pointer position
F1              - show help screen (context-dependent)
Shift-F1        - show resources in this position next turn
F2              - save data changes without leaving VPA
Shift-F2        - show ships in this position next turn
F3              - switch to message processor
Shift-F3        - send selected object data to other player(s)
F4              - print report (to printer or file)
F5              - switch to combat simulator
F6              - switch to planet economy simulator
F7,Shift-F7     - find planet or ship by name or ID number
F9              - draw a circle on the map
Ctrl-H          - draw hyperjump circles (340-360 LYs radius)
Shift-F9        - calculate and draw a projected mine field
Alt-F9          - calculate and draw a projected mine field with given radius
F10             - show game score and Power Graph
Shift-F10       - mine field simulator
Alt-P           - change player password
Alt-X,Alt-F4    - exit VPA
Ctrl-Alt-X      - exit without saving changes
Ctrl-P          - show used PBx codes
#               - switch to quality assurance overview list
Ctrl-A          - approve current planet/ship/base, i.e. activate it in the
                  actual list
Ctrl-D          - disapprove current planet/ship/base, i.e. deactivate it in
                  the actual list
Ctrl-N          - view and edit note attached to ship or planet (if selected)
Ctrl-F10        - switch to resource statistics screen
Ctrl-F11        - switch to fleet overview screen
Ctrl-E          - display temporary territory overview on map (experimental)
Shift-F11       - show "common mistakes" for ships (like low speed, insuff.
                  fuel, ...) or planets (taxes, ...)
Ctrl-Z          - Reset Waypoint of all ships that have a waypoint in the
                  local warpwell and speed>1
Ctrl-O          - Show and edit VPA Configuration (vpa.ini)

PLANET INFO SCREEN
------------------

,->           - select previous/next planet you own (by ID no.)
                  In keyboard-only mode: Ctrl-,->
, .             - select previous/next planet you own (by actual)
/               - activate/deactivate planet in actual list
O               - select nearest planet in actual list
Shift-O         - deactiviate planet and select nearest active planet
B               - switch to starbase info screen (if have one)
                  or build a starbase (if you have 402 Tr, 120 Du,
                  340 Mo and 900 mc on the planet surface)
T               - set tax level for natives (if any) [M.O.T.]
Ctrl-T          - calculate projective taxes for natives (if any)
X               - set tax level for colonists [M.O.T.]
A,M,D           - build factories, mines, defense outposts [M.O.T.]
S               - sell supplies [M.O.T.]
F               - change planetary friendly code
Ctrl-F          - change friendly code on all planets that
                  have the same fc as the selected planet
R               - set random planetary friendly code
Ctrl-R          - set the same random friendly code on all planets
                  that have the same fc as the selected planet
Alt-R           - randomize all planetary friendly codes
                  (except planets with "ATT", "NUK" and "mf?" codes)
Alt-U           - unload cargo from all your ships in orbit
F6              - insert this planet into planet economy simulator
Shift-J         - toggle colonist prediction in planet info
Ctrl-B          - switch to borgculator screen
Shift-H         - toggle ShowFinalHappy


STARBASE INFO SCREEN
--------------------

,->            - select previous/next base you own (by ID no.)
                  In keyboard-only mode: Ctrl-,->
, .             - select previous/next base you own (by actual)
/               - activate/deactivate base in actual list
P               - switch to planet info screen
O               - set base mission (order)
D               - increase base defense factor [M.O.T.]
T               - upgrade base tech levels [M.O.T.]
F               - fix damaged ship
R               - recycle useless ship
Home,End        - browse base storage (if exceeds 1 page)
Y               - build torpedoes or fighters [M.O.T.]
B               - switch to ship construction screen
C               - clone other race's ship design (if have one)


SHIP INFO SCREEN
----------------

,->            - select previous/next ship you own (by ID no.)
                  In keyboard-only mode: Ctrl-,->
, .             - select previous/next ship you own (by actual)
/               - activate/deactivate ship in actual list
O               - select nearest ship in actual list
Shift-O         - deactiviate ship and select nearest active ship
P               - switch to planet info screen (if at planet)
B               - switch to starbase info screen (if at base)
Home,End        - browse possible hull type list (for enemy ship
                  with unknown hull type)
A               - show all possible hull types or ship designs
                  belonging to the enemy ship's race only
H               - assume hull type for enemy ship of unknown type
N               - rename ship
M               - set ship mission
E               - set primary enemy
F               - (foreign ship) forget assumed hull type
                - (own ship) set friendly code
Ctrl-F          - change friendly code on all ships that
                  have the same fc as the selected ship
Shift-F         - display hull functions
R               - set random friendly code
Ctrl-R          - set the same random friendly code on all ships
                  that have the same fc as the selected ship
Y               - build torpedoes/fighters and load them onto
                  the ship (at starbase) [M.O.T.]
C               - load/unload/jettison cargo [M.O.T.]
T               - transfer cargo to/from other ships [M.O.T.]
U               - unload ship cargo (at planet)
L               - load ship for torpedo/fighter building
                  (when applicable) [M.O.T.]
I               - Fix damaged ship (must be at starbase)
W               - set warp factor
V               - (PHost only) give ship away using "give" command message
Shift-B         - show ship build costs
Shift-C         - (PHost only) remote control (command message)
Shift-F9        - calculate projected mine field (for torp. ships)
Ins             - set a marker and bind it to the ship
Spacebar        - enter Distance Mode

In Distance Mode:
0..9            - set warp factor
N               - move anchor point to location where the ship
                  will be next turn if proceed to the specified
                  waypoint at current speed. Use it recursively
                  to calculate complicated routes step-by-step.
                  Time and fuel consumption is accumulated.
G               - adjust pointer to the edge of planetary warp
                  well (planet must be selected and HCONFIG
                  gravity setting must be enabled)
Alt-I           - activate drag-prediction when in class 4 or 5 ion storm
Ctrl-Enter      - set waypoint to the pointer location
Spacebar        - exit Distance Mode

Left Mouse Button is functionally equal to the Enter key
Right Mouse Button is functionally equal to the Spacebar key


MARKER INFO SCREEN
------------------

T               - input label text
A               - align label text placement
R               - enter radius (for r-circle only)
Del             - erase marker


MINEFIELD INFO SCREEN
---------------------

R               - how many mines do I need to increase the radius by...?
T               - cycle beam types for sweep prediction


CONSTRUCTION YARD
-----------------

,->,,        - choose hull, engine and weaponry type
PgUp,PgDn       - move selection by 5 units up/down
B               - change number of beams (when applicable)
T               - change number of torpedo tubes (when applicable)
+               - build ship parts manually
-               - scrap ship parts built on the current turn
S               - start/cancel ship construction
N               - show prediction of next turn available resources
Shift-F         - display hull functions
Esc             - switch back to starbase info screen


MESSAGE EDITOR
--------------

,->,Home,End   - navigate through messages of the same type
,             - cycle through message types (inbound,
                  outbound, VCR)
S               - save message text to a file
R               - reply inbound message with quoting
F               - forward message to other player(s)
N,Ins           - create new outbound message
L               - load message text from file
E               - edit outbound message text
D,Del           - delete outbound message
V               - view VCR record
M               - show mentioned location/object on the map
Enter           - default action shortcut (depending on the
                  message type and contents)
Esc             - exit from message editor


COMBAT SIMULATOR
----------------

,->,,        - cursor movement
+,-,Enter       - change combatant configuration
Spacebar        - use real ship/planet from the current
                  game as a combatant
Tab             - swap combatants (ship-to-ship combat)
E               - set Engine-Shield Bonus value
F               - turn Fed Crew Bonus on/off
L               - turn Anti-LeftWin feature on/off
A               - turn combat animation on/off
O               - turn combat sound on/off
1..9            - adjust combat animation speed
S               - start combat simulation with next random seed
Shift-S         - start combat simulation with previous random seed
V               - re-view last simulated battle
R               - accept combat results for using in the next
                  simulation (survived combatants only)
Esc             - exit from combat simulator

During the animated phase of simulation:
1..9,+,-        - adjust combat animation speed
Esc             - skip animation and get the result immediately
Spacebar        - turn single step mode on

In single step mode:
Spacebar        - perform a single step of combat
Enter           - turn single step mode off


SCORE SCREEN
------------

+,-             - view next/previous turn scores
Ctrl/+,-        - view last/first turn score
Shift/+,-       - change turn number to compare current turn score with
Esc             - exit from score screen


MOVE-OR-TYPE (M.O.T.) INTERFACE
-------------------------------

,->            - change value by 1 or move/build 1 unit
Ctrl-,->       - change value by 10 or move/build 10 units
Alt-,->        - change value by 100 or move/build 100 units
Shift-,->      - change value to the minimum/maximum
                  or move/build none/all
0..9            - manually input the value
,             - move cursor vertically (when applicable)
Tab             - move cursor horizontally (when applicable)
Enter,Esc       - exit the M.O.T. mode

Note: during a planet-to-ship cargo transfer, after all credits from
      the planet are loaded onto the ship, all further money loading
      commands will automatically sell supplies from the planet and
      load them as credits onto the ship.
