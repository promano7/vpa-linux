# VPA-Linux

**🇬🇧 English.** VPA-Linux is a native GNU/Linux port of **VGA Planets Assistant
(VPA) 3.67**, the classic client for the play-by-email strategy game *VGA
Planets 3*, rebuilt with Free Pascal from the original Turbo/Borland Pascal DOS
source. It's playable end-to-end (star map, ships, planets, StarBases, messages,
and a native bit-exact PHost combat viewer) with no DOSBox or dosemu involved.

- 🔧 Build from source: **[`BUILD.en.md`](BUILD.en.md)**
- ▶️ Run the pre-built binary: **[`HOWTO.en.md`](HOWTO.en.md)**

**🇪🇸 Español.** VPA-Linux es un port nativo a GNU/Linux de **VGA Planets
